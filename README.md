# bonzo — portfolio

制作者bonzoの公式ポートフォリオ。ゲームシステム・UI設計、音楽・サウンド、AIを活用した制作管理を紹介する日本語・英語の静的サイトです。

代表作品：[キョウトユウギ](https://kyoutoyuugi-official-site.pages.dev/)。ゲーム本編ソースは含みません。

## Build

Node.js 22。外部依存パッケージなし。

```sh
npm run build && npm run check
```

出力は `dist/`。[Cloudflare Pagesの設定](DEPLOYMENT.md)、[進捗と再開手順](WORK_PROGRESS.md)を参照してください。

音源は正式ファイルと公開範囲の確認後に登録します。問い合わせ先やnoteは確認前に補完しません。画像・映像・作品名の権利は各権利者に帰属し、このリポジトリはゲーム素材の再利用許諾を付与しません。
